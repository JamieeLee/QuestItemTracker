# Quest Item Tracker

A lightweight World of Warcraft Forever addon that identifies quest items, tracks current and future quest requirements, and tells players when leftover items are safe to delete.

## Current baseline

- **Last known-good version:** v0.3.4
- **Game interface:** 16001
- **Optional data dependency:** QuestieDB (the full Questie addon is not required)
- **License:** GNU GPL-3.0

The playable v0.3.4 addon source is in [QuestItemTracker/](QuestItemTracker/).

This repository preserves v0.3.4 as the baseline. Upcoming automatic-sync and item-lifecycle improvements are developed separately and will be proposed through pull requests.
